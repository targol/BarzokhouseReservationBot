# راهنمای اجرای ربات اقامتگاه «خانه برزک» در حالت بدون سرور (Telegram Serverless)

این نسخه به طور کامل بر پایه معماری نوین **Telegram Serverless** بازنویسی شده است؛ به این معنی که کدهای ربات مستقیماً داخل زیرساخت ابری امن و پرسرعت تلگرام اجرا می‌شوند و **به هیچ سرور خارجی (مثل Render، VPS یا هاست‌های پولی)** نیازی ندارید.

---

## 🌟 مزایای اجرای ربات روی Telegram Serverless
1. **بدون به خواب رفتن سرور (No Cold Starts):** در هاست‌های رایگان خارجی مثل Render، سرور بعد از ۱۵ دقیقه بی‌کاری به خواب می‌رود و اولین پیام با تأخیر پاسخ داده می‌شود. در تلگرام سرورلس، پاسخ‌ها در کسری از ثانیه ارسال می‌شوند.
2. **کاملاً رایگان و پایدار:** بدون نیاز به تمدید، دامنه‌های واسط یا کارت اعتباری.
3. **پایگاه داده داخلی (SQLite):** نگهداری وضعیت رزرو، سبد غذا و مراحل مکالمه با سرعت بالا در خود تلگرام.
4. **عدم ریسک فیلترینگ سرور یا اختلال ارتباطی:** سرورها مستقیماً در کنار شبکه اصلی Bot API تلگرام قرار دارند.

## 📋 ساختار فایل‌های نسخه سرورلس
```text
serverless/
├── package.json              # مشخصات پروژه و دستور deploy
├── config.js                 # پیکربندی متون، قیمت‌ها، اطلاعات تماس و اتاق‌ها
├── utils.js                  # الگوریتم‌های تبدیل تاریخ شمسی به میلادی، تقویم و ارقام
├── db.js                     # سیستم مدیریت Session و وضعیت چند مرحله‌ای رزرو
├── keyboards.js              # کیبوردهای شیشه‌ای تعاملی (رزرو، سنین کودکان، غذاها)
├── rooms.json                # داده‌های پایدار اتاق‌ها
├── foods.json                # داده‌های پایدار غذاها
├── index.js                  # نقطه ورود اصلی و وب‌هوک فراگیر
├── handlers/
│   ├── message.js            # مدیریت دستورات، پیام‌های متنی و رسیدهای واریزی
│   └── callback_query.js     # مدیریت کلیک روی دکمه‌ها و ثبت نهایی درخواست‌ها
└── README.md                 # این راهنما
```

## 🚀 راهنمای راه‌اندازی و دیپلوی (کمتر از ۳ دقیقه)

### مرحله ۱: دریافت دسترسی Serverless در تلگرام
1. در تلگرام به ربات رسمی **[@BotFather](https://t.me/BotFather)** مراجعه کنید.
2. دستور `/mybots` را بفرستید و ربات خود را انتخاب کنید.
3. به بخش **Bot Settings** بروید.
4. گزینه **Serverless** (یا **Cloud Execution**) را انتخاب کرده و روی **Enable** کلیک کنید.
5. یک **Access Token** برای دیپلوی از طریق CLI به شما نمایش داده می‌شود؛ آن را کپی کنید.

### مرحله ۲: اجرای دستور دیپلوی با کامپیوتر یا ترمینال
وارد پوشه `serverless` شوید و دستور زیر را اجرا فرمایید:

```bash
cd serverless
npx tgcloud push
```
در اولین اجرا، توکن CLI که از BotFather گرفتید را وارد می‌کنید. تمام فایل‌ها فوراً در زیرساخت تلگرام بارگذاری و فعال می‌شوند.

### مرحله ۳: تنظیم متغیرهای محیطی
در صورتی که توکن ربات یا آیدی چت ادمین را در فایل `config.js` وارد نکرده‌اید، می‌توانید از طریق BotFather یا متغیرهای محیطی آن‌ها را تنظیم کنید:
- `BOT_TOKEN`: توکن اختصاصی ربات تلگرام شما
- `ADMIN_CHAT_ID`: آیدی عددی ادمین یا گروه مدیران (مثلاً `-1004485664573`)
